# Changelog

## 1.1.0

- Added Crypto Lab: eight interactive workspaces powered by the repository's
  own algorithms, with no additional runtime dependencies.
- Added editable GCM verification, an avalanche bit grid, Euclid traces,
  Alice/Bob exchanges, channel rejection events and live experiment results.
- Added a loopback-only HTTP launcher, input/work limits, same-origin checks,
  packaged browser assets and JSON result exports.
- Redesigned the interface with responsive layouts, keyboard focus, labelled
  inputs, accessible status updates and textual explanations.
- Made the whole interface English, including examples, help, validation
  errors, status messages and refreshed browser captures.
- Rewrote the README and animated walkthrough in English, with actual browser
  captures, an interface GIF and research-backed design notes.
- Added algorithm-reference and HTTP tests, browser interaction checks, and
  a Chromium verification job in CI.

## 1.0.0

- Parcours V1–V14 complété avec AES-128/192/256 et AES-GCM implémentés en Python.
- HMAC-SHA256, signatures RSA pédagogiques et canal DH authentifié avec anti-rejeu.
- Factorisation réutilisable, cinq simulations d'attaques et études A–F.
- Comparaisons indépendantes AES/GCM, vecteurs connus et tests de validation.
- Rapports JSON, graphiques, dix GIFs pédagogiques et leurs alternatives fixes.
- README détaillé, référence API, matrice du cahier des charges et CI.

Il s'agit d'une version complète du projet éducatif, pas d'une validation de
sécurité pour un usage en production.
