PROJET AUTODIDACTE — CRYPTO-FROM-SCRATCH
===========================================

Titre
-----
Crypto From Scratch — Bibliothèque cryptographique éducative développée avec Python

OBJECTIF
--------
Construire progressivement une bibliothèque cryptographique en implémentant soi-même
les principaux mécanismes mathématiques et algorithmiques utilisés en cryptographie.

Le projet doit servir à comprendre :
- l'arithmétique modulaire ;
- la théorie des nombres ;
- les nombres premiers ;
- RSA ;
- Diffie-Hellman ;
- les fonctions de hachage ;
- le chiffrement symétrique ;
- les bases des protocoles sécurisés.

IMPORTANT
---------
Ce projet est éducatif.

Les algorithmes implémentés "from scratch" ne doivent pas être considérés comme
suffisamment sûrs pour protéger de vraies données. En production, utiliser des
bibliothèques cryptographiques reconnues et auditées.

============================================================
5. V3 — RSA
============================================================

Implémenter RSA à des fins éducatives.

Processus :

    p, q
     |
     v
    n = p × q
     |
     v
    φ(n)
     |
     v
    choix de e
     |
     v
    calcul de d
     |
     v
    clés
     |
     +----------+
     |          |
     v          v
    Public    Privée

Clé publique :

    (n, e)

Clé privée :

    (n, d)

Chiffrement :

    c = m^e mod n

Déchiffrement :

    m = c^d mod n

Implémenter :
- génération de clés ;
- chiffrement ;
- déchiffrement ;
- sérialisation des clés ;
- tests.

IMPORTANT :
Ne pas implémenter uniquement la formule RSA brute comme si elle était une version
sécurisée de RSA moderne. Documenter les problèmes liés au padding et montrer pourquoi
RSA-OAEP est nécessaire en pratique.

============================================================
7. V5 — DIFFIE-HELLMAN
============================================================

Implémenter un échange de clé Diffie-Hellman.

Principe :

    Alice                         Bob

      a                             b
      |                             |
      v                             v
    g^a mod p                    g^b mod p
      |                             |
      +---------- échange ---------+
      |                             |
      v                             v
    (g^b)^a                       (g^a)^b
             \                   /
              \                 /
               SECRET COMMUN

Les deux parties doivent obtenir :

    g^(ab) mod p

Expérimenter avec différentes tailles de paramètres.

Puis documenter :
- pourquoi le secret n'est pas envoyé ;
- problème du logarithme discret ;
- attaque Man-in-the-Middle ;
- nécessité d'authentifier les parties.

8. V6 — FONCTION DE HACHAGE
============================================================

- déterminisme ;

- résistance à la seconde préimage ;
- résistance aux collisions ;
- effet avalanche.

Créer d'abord un petit hash pédagogique.

Puis étudier l'architecture d'un algorithme réel comme SHA-256.

L'objectif peut être d'implémenter SHA-256 pour comprendre :
- padding ;
- blocs ;
- fonctions logiques ;
- rotations ;
- constantes ;
- compression ;
- état interne.

Comparer ensuite le résultat avec une implémentation standard.

Ce projet combine :

    THÉORIE DES NOMBRES
           +
    MATHÉMATIQUES
           +
    ALGORITHMIQUE
           +
    PROGRAMMATION
           +
    CYBERSÉCURITÉ

Le but n'est pas de créer une bibliothèque cryptographique destinée à remplacer
